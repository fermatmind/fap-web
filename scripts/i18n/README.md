# Offline Taiwan Traditional Chinese

Run `pnpm i18n:zh-TW` to prepare the explicitly allowlisted, code-owned Chiikawa question bank, complete result additions, UI strings, About team copy and ContentPage template labels. `pnpm i18n:zh-TW:check` rejects stale resources and runs before production builds. OpenCC is pinned to **opencc-js 1.4.2**, `cn → twp`; the lockfile binds package integrity. MIT and dictionary Apache-2.0 notices are retained under `public/licenses/`. No translation API or service is used, and OpenCC is absent from the browser runtime.

The checked-in resource package stores translations with target locale, field context, source-text hash, converter version and glossary version; unchanged units are reused. Whole-source hashes bind the package to current source files, including identity/configuration changes. Each declared package is written with optimistic source/target checks and atomic replacement. Git and the existing release pipeline own rollback. `--check` does not write.

Only existing `{zh, en}` reader fields in the explicit `packages` source lists are extracted. The Chiikawa/UI package has five sources; Seven Sins content and UI retain their separate package lists. Keys, IDs, slugs, scores, counts, references' URL destinations, configuration and source attestations are never translated. Numbers, literal URL destinations, code spans and substitution tokens inside prose remain byte-for-byte intact. These sources contain plain text, not Markdown/HTML/ICU documents. Adding a different format or CMS family requires its own parser/field allowlist and original authority/import transaction; this command does not accept arbitrary directories, database payloads or private reports.

`content-page-zh-tw.mjs` prepares an unpublished candidate from one published `zh-CN` ContentPage public projection. It allowlists reader metadata, headings, simple Markdown and FAQ question/answer fields, binds source and per-field hashes, and excludes publication flags and identifiers from its output fields. Its initial Markdown adapter supports headings, paragraphs and lists used by the selected About page; it rejects HTML, code, images, links and tables rather than converting their syntax or destinations as plain text. It performs no network/database writes and does not replace native source-revision locking, review, publication, cache closeout or rollback. Richer CMS formats need their own adapter before their pages can be opened.

The route capability module (`lib/i18n/traditionalRoutes.ts`) is the current public page whitelist. Private `/take` flows stay outside indexing and shared caching. The CMS About reader is prepared but remains outside that whitelist until its native variant is published and accepted. Only complete equivalents receive language alternates. Display locale is separate from existing API/form locales: the general `apiLocaleForDisplay("zh-TW")` still returns `null`, while the ContentPage consumer explicitly requests its genuine `zh-TW` CMS variant. No form/report language, commercial region, pricing or entitlement policy is inferred.

Before extending the whitelist, check complete questions, options, negation/conditions, all result/tie variants, public share return paths and mobile layout. Conversion alone does not validate regional terminology, claims, psychometrics or local policy. The first release preserves this original fan quiz's meaning and scoring; it does not claim Taiwanese psychometric validation.
