# Offline Taiwan Traditional Chinese

Run `pnpm i18n:zh-TW` to prepare the explicitly allowlisted, code-owned Chiikawa question bank, complete result additions and UI strings. `pnpm i18n:zh-TW:check` rejects stale resources and runs before production builds. OpenCC is pinned to **opencc-js 1.4.2**, `cn → twp`; the lockfile binds package integrity. MIT and dictionary Apache-2.0 notices are retained under `public/licenses/`. No translation API or service is used, and OpenCC is absent from the browser runtime.

The checked-in resource package stores translations with target locale, field context, source-text hash, converter version and glossary version; unchanged units are reused. Whole-source hashes bind the package to current source files, including identity/configuration changes. The converter writes a single file with optimistic source/target checks and atomic replacement. Git and the existing release pipeline own rollback. `--check` does not write.

Only existing `{zh, en}` reader fields in the three explicit source files are extracted. Keys, IDs, slugs, scores, counts, references' URL destinations, configuration and source attestations are never translated. Numbers, literal URL destinations, code spans and substitution tokens inside prose remain byte-for-byte intact. These sources contain plain text, not Markdown/HTML/ICU documents. Adding a different format or CMS family requires its own parser/field allowlist and original authority/import transaction; this command does not accept arbitrary directories, database payloads or private reports.

The route capability module limits publication to `/zh-TW`, `/zh-TW/tests`, the Chiikawa landing and six guides; `/take` is usable but excluded from indexing and caching. Other pages return 404. Only the seven equivalent quiz/guide pages have three-way language alternates. Hub links explicitly label original-language content. Display locale is separate from the existing API/form locales, and `apiLocaleForDisplay("zh-TW")` returns `null`: no form/report language, commercial region, pricing or entitlement policy is inferred.

Before extending the whitelist, check complete questions, options, negation/conditions, all result/tie variants, public share return paths and mobile layout. Conversion alone does not validate regional terminology, claims, psychometrics or local policy. The first release preserves this original fan quiz's meaning and scoring; it does not claim Taiwanese psychometric validation.
