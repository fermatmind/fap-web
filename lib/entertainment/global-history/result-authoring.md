# 全球卷人物数据生成约束

批量生成 Prompt 使用以下约束。

> 六维故事向量采用题库 `questions.ts` 中 `historyAxes` 的固定顺序，每个维度取 0–6 的整数。保留已有角色向量。输出人物向量及获授权的传记文案字段。禁止输出独立的六维主标签、副标签或取向，也禁止为迎合人物称号、MBTI 或大五标签而反转维度。
>
> 页面只从向量推导成对标签。0–2 分选择该维度低端，3 分选择中性，4–6 分选择高端。主标签使用 `result-v2.ts` 中该维度同一方向的网感文案，副标签使用题库同一方向的原始文案。例如「一开口就组局」仅对应协作高端「先把人聚在一起」。
>
> 大五标签用高／低与标准维度名组合。可用维度为开放性、尽责性、外倾性、宜人性、神经质。标签属于传记演绎。

现有名册保留向量和 ID。新增人物把逐轴观察记入 `new-vector-evidence.json`，键与题库定义的轴一一对应。分数是对已列史料情境的编写判断，证据不充分时保留待审状态。禁止把估值、职业头衔或主副标签倒推成六维分数。

Cox 核对表用原表编号和行号定位，只绑定审定后的人物 ID。未挂接名册的 Cox 行保留原数值与出处，暂不进入匹配或推荐。

`candidate_wikidata_id` 来自姓名和生卒年交叉初筛，仅供后续身份审读。它不会生成 URL 或匹配结果。简中、繁中海报字集覆盖人物姓名、称号、判词、标签和海报文案，更新内容时重新生成并检查导出。
