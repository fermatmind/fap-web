# Original self-report questionnaires

This code-owned preview family uses the explicit collection in `catalog.json`: new entries at `/{locale}/tests/explore/{slug}` and in-place upgrades of the same existing product at `/{locale}/tests/play/{slug}`. It contains FermatMind's original website reflections and adaptations of its owned mini-program questionnaires, preserving each published edition's actual questions, scoring rules and complete report content. It is not a fallback or editorial override for backend-registered assessments. The existing core tests, question APIs, scoring and reports retain backend authority.

`catalog.json` contains only discovery metadata and public report IDs. `loaders.ts` uses explicit per-product imports; the hub must not import the question banks. Each complete bilingual package records its source question/scoring/content versions and hashes. Private answers are evaluated in browser memory. Optional tab drafts expire after 24 hours and clear on completion, exit-and-clear or retake. A public result explanation is not a visitor's saved result.

DISC uses the original 24 paired choices. Each direction appears 12 times; selected options add one raw count. Highest counts retain every tie and select the corresponding authored report. No partial interpretation, population norm, official commercial certification, career-fit inference or MBTI conversion is added. The four-way tie sentence is clarified to say all four counts are equal; it does not compare them with nonexistent remaining directions. Website storage notices describe the actual opt-in tab behavior rather than the mini-program's record store.

The complete color edition replaces the former concise adaptation at `/tests/play/response-color`. Its four single-report identities (`red`, `yellow`, `blue`, `green`) stay stable; all eleven tied reports are added at that same entry. There is no second `/tests/explore/response-color` entry. Catalog collection metadata selects the existing route, and only the explicitly listed loader can provide its original question and report package. The legacy entertainment data remains compatibility evidence; it is not rendered for this upgraded identity.

Social Battery is an original 20-item website reflection, not an introversion rename or a research team’s instrument. Four independent sets of five frequency items describe interaction load, coordination load, quiet recovery and easy company. Eight listed reverse items use `6 - response`; explicit non-experienced responses are excluded. At least three rated items are needed for each mean, an editorial data-completeness rule rather than a psychometric cutoff. Every part is presented, including explicit insufficient-information states, without a total, diagnostic/type assignment or battery percentage. Public guides contain no personal means. The cited small experience-sampling studies supply context only; they do not validate these original items or dimensions.
