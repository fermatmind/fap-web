# Database administrators vs. librarians and media collections specialists

## A working database and a useful catalog

Database administrators maintain the database and test changes to it. Librarians and media collections specialists help people find information and make decisions about descriptions, collections and services. In the same catalog project, each is checking a different result.

## Compare the work

| Item | Database administrator | Librarian or media collections specialist |
| --- | --- | --- |
| Deliverable | Database change checks and records of data and recovery testing | Verified descriptions, catalog searches and collection or service decisions |
| Setting to ask about | IT team, change windows and support shifts | Library service desks, collections or teaching spaces |
| Typical U.S. entry education | Bachelor's degree | Master's degree |
| 2025 U.S. median annual wage | $104,620 | $68,270 |

Wages cover nonfarm wage and salary workers and exclude self-employment. ## The counts match, but the search is wrong

At a fictional library, the database administrator verifies that all 1,000 catalog records imported into a test environment and records the backup recovery check. A librarian finds three oral histories incorrectly labeled as photographs. The librarian confirms the intended classification and proposes a search to check it. The administrator implements the approved mapping correction and checks the count again. The librarian verifies search results, then the project lead decides whether both acceptance records support release.

## Getting started in the U.S.

BLS lists a bachelor's degree as typical for database administrators. Ask which database systems the employer uses and which skills the job tests. A sample test or recovery verification report can demonstrate relevant work. Librarians typically need a master's in library science or a related program. Public school librarians and library media specialists typically need teacher certification, and some states require a test. Check the state education department for school roles. Some states also require certification for librarians in public libraries; check the applicable state licensing authority. [BLS typical preparation](https://www.bls.gov/emp/tables/occupational-projections-and-characteristics.htm) · [BLS librarian preparation](https://www.bls.gov/ooh/education-training-and-library/librarians.htm#tab-4)

## Ask what happens outside normal hours

Ask the database team who responds to alerts and who approves changes during maintenance windows. Ask the library team how service desk shifts fit with collection work and who decides catalog exceptions.

## Moving between the roles

A database administrator can bring a redacted migration test and handoff note, then study cataloging, collection services and user searches. A librarian can bring a redacted metadata map and search discrepancy record, then develop database operation, recovery testing and change documentation skills.

## A 30-minute paper exercise

Use fictional records only. A test import still has 1,000 items and recovery testing passes, but three oral histories appear under photography. The library requires both data and search checks before release. Take ten minutes to mark what passed and what must wait, ten to draft the librarian's classification decision and the administrator's recheck, and ten to write a recommendation to the project lead. State who corrects the mapping, who verifies the searches and who authorizes release.
