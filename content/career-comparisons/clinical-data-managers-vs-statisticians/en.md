# Clinical Data Manager vs. Statistician: Resolving a Follow-Up Date Discrepancy

## What each role delivers

A clinical data manager oversees the study database, data verification and dataset delivery. A statistician selects analysis methods and checks how corrections affect results.

## Compare the work

| Work item | Clinical Data Managers | Statisticians |
|---|---|---|
| Output | Query record, locked version and handoff | Analysis classification, estimate and impact note |
| Basis | Source records, change authorization and checks | Analysis target, time window, missingness and comparison rules |

## How the work meets

In a fictional rehabilitation study, two tables disagree on a follow-up date. The clinical data manager sends a query, records the verified source response and provides a corrected version. The statistician checks whether the record moves to a different analysis visit under the agreed window and compares output versions.

## How to enter

BLS lists a master’s degree as typical for statisticians. In O*NET’s survey of education needed by new clinical data managers, 85% of respondents selected a bachelor’s degree. [O*NET education for clinical data managers](https://www.onetonline.org/link/summary/15-2051.02#Education) Clinical data candidates can show database checks and a documented data handoff. Ask how privacy, review and release are handled. [BLS occupation table](https://www.bls.gov/emp/tables/occupational-projections-and-characteristics.htm)

## Work conditions

Data management follows collection, queries and lock. Statistics follows the analysis plan, dataset availability and reporting. Ask how changes are communicated.

## Moving between roles

Data managers can bring data provenance and checks to statistics and add estimation and sensitivity analysis. Statisticians can bring verification skills to data management and learn database workflows and access controls.

## Try it in 30 minutes

Mock file: one table says day 14, another says day 17 and the source is unconfirmed. The analysis window is days 12–16. Spend ten minutes each on a query and version note, classification under both dates, and what must be verified before rerunning results.
