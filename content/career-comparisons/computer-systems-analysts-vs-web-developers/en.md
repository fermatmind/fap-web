# Computer Systems Analysts vs. Web Developers: Building a Reschedule Form

## What each role delivers

Systems analysts define how a change affects inventory and booking records. Web developers build the form, handle responses and test the resulting page behavior.

## Compare the work

| Work item | Computer Systems Analysts | Web Developers |
|---|---|---|
| Output | Business acceptance and integration rules | Working page and test evidence |
| Basis | Inventory status and reservation records | Form behavior, outcomes and device checks |
| U.S. median annual wage (2025) | $105,850 | $92,650 |

## How the work meets

A fictional event site adds rescheduling. The analyst finds that the old seat must remain booked until a new seat is confirmed. The developer implements the form and verifies that the original reservation still appears when the new slot is full.

## How to enter

BLS lists a bachelor’s degree as typical entry education for both roles. For systems analysis, show requirements and acceptance work. For web development, show a working feature and tests and ask how the employer divides page and API responsibilities. [BLS occupation table](https://www.bls.gov/emp/tables/occupational-projections-and-characteristics.htm)

## Work conditions

Analysts resolve exceptions with operations and technical teams. Developers handle implementation, review and retesting. Ask where issues involving the page, the API or the booking record are routed.

## Moving between roles

Moving into development, use your rules and test cases and add web implementation and debugging. Moving into analysis, build on integration experience and add stakeholder interviews and requirements ownership.

## Try it in 30 minutes

Use three mock cases: the new slot is open, the new slot is full and confirmation is delayed. Spend ten minutes each on acceptance criteria, page feedback and test expectations, and a decision the product owner still needs to make.
