# Search Marketing Strategists vs. Web Developers: Who Owns a URL Migration?

## What each role delivers

During a URL migration, a search marketing strategist identifies existing search entry pages and proposes what should carry over. A web developer turns the approved requirements into working code and tests and reports any exceptions found during implementation.

## Compare the work

| Compare | Search marketing strategist | Web developer |
|---|---|---|
| Inputs | Search traffic and page mappings | Routes, templates, and test results |
| Outputs | Migration priorities, URL map, and post-launch review | Redirect implementation, regression tests, and release checks |

[O*NET 13-1161.01](https://www.onetonline.org/link/summary/13-1161.01#Tasks) · [O*NET 15-1254.00](https://www.onetonline.org/link/summary/15-1254.00#Tasks)

## The same migration

Imagine a bookstore chain moving its store pages. The strategist prioritizes pages that receive search traffic, confirms their new addresses, and flags a closed store with no replacement page. The developer implements the approved mapping and checks that similarly named stores go to distinct destinations. After launch, the strategist reviews traffic to the destination pages and the developer addresses confirmed implementation defects.

## Getting started in the U.S.

O*NET places search marketing strategists in Job Zone Four, which generally involves considerable preparation. For a strategy portfolio, show a URL map with priorities and follow-up checks. For development, include code and tests from a small site migration. BLS says education requirements vary, and some employers prefer a degree in computer science, programming, or a related field. [O*NET Job Zone](https://www.onetonline.org/link/summary/13-1161.01#JobZone) · [BLS education guidance](https://www.bls.gov/ooh/computer-and-information-technology/web-developers.htm#tab-4)

## Working conditions

The strategist needs input from store operations and time for search data to accumulate. Developers need time before release to review code and test results. Ask when migrations go live and who handles problems during the release window.

## Changing roles

From strategy to development, bring your experience writing acceptance criteria and learn routing, code review, and automated testing. From development to strategy, bring your knowledge of site structure and learn to set migration priorities using search data.

## Try both in 30 minutes

Use three fictional old URLs: `/shops/pine`, `/shops/pine-east`, and `/shops/old-mill`. The proposed destinations for the first two are `/stores/pine-central` and `/stores/pine-east`. The third store closed with no replacement page. Spend 10 minutes mapping destinations and flagging the exception, 10 writing expected tests for both redirects and the closed page, and 10 deciding what each role checks after launch.
