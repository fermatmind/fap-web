# Electricians vs Manufactured Building and Mobile Home Installers

## Unit setup and electrical systems

Electricians install and maintain power, lighting, and related electrical systems. Manufactured building and mobile home installers move and set up units, and some assignments include fixtures or connections. A site can require both skills, with the work and acceptance assigned separately.

## Work, U.S. preparation, and pay

| Item | Electricians | Manufactured building and mobile home installers |
| --- | --- | --- |
| Output | Electrical installation or repair and verification record | Unit setup record and interface handoff |
| Typical setting | Building site or facility maintenance | Installation site, lot, or mobile home park |
| Typical entry education | High school diploma or equivalent | High school diploma or equivalent |
| Typical training | Apprenticeship | Short-term on-the-job training |
| 2025 U.S. median annual wage | $63,190 | $45,990 |

## The setup record starts the next handoff

In a fictional prefab project, the installer checks unit placement against the approved layout, records it, and supplies the interface location to the electrician. The electrician compares that handoff with the approved electrical drawing and site record and flags unclear information for the electrical lead. The project lead tracks setup and electrical acceptance separately before updating the overall delivery.

## Training and authorization

Compare electrician apprenticeships and check state or local licensing. For installation jobs, ask which setup tasks are taught under supervision. For the initial installation of a covered new manufactured home, confirm whether HUD or a qualifying state administers the program and check the applicable installer license and supervision rules. Check other prefab or relocation assignments with the authority for that dwelling and site. [BLS electrician entry](https://www.bls.gov/ooh/construction-and-extraction/electricians.htm#tab-4) · [HUD manufactured home installation program](https://www.hud.gov/hud-partners/manufactured-home)

## What changes a workday

Ask electricians how changes to drawings and site access affect scheduling. Ask installers how delivery windows, site access and coordination with other trades affect setup.

## A supervised starting point in either direction

Moving into building setup, bring a fictional electrical handoff record and start with supervised layout and interface checks. Learn unit placement records and setup schedules. Moving into electrical work, bring a fictional interface discrepancy and start with supervised drawing and work-order checks. Learn the electrical training and licensing path.

## Try a 30-minute desk exercise

Use a different fictional unit. Setup record S-39 shows placement completed as planned and interface E4. Approved electrical drawing P-39 still shows E3 and there is no approved change. Spend ten minutes separating confirmed facts from open issues, ten minutes writing a setup handoff and a drawing review request, and ten minutes telling the project lead which record can be submitted for review and which item remains open. Work from the records only.
