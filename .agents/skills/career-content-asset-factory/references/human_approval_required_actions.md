# V2 Routing And Independent-Control Actions

A concrete end-to-end `/goal` continuously authorizes the scoped Career package
through evidence, repair, freeze, independent W9/QA, and trusted backend V2
promotion. The package SHA is integrity, idempotency, audit, and rollback
evidence; it is not a human-approval credential.

## Trusted V2 Route

For a registered, audit-compatible exact backend-authority package, dispatch
only the trusted fap-api workflow. It performs dry-run, draft import, readback,
publish, and live QA in order. A failed gate is a machine-gate repair or
recovery task in the same Producer PR, never an approval-only, reset, or
status-acceptance PR.

## Direct Actions That Stay Forbidden Here

- Direct staging, CMS, or production imports from Producer code.
- Direct published-pointer mutation outside the trusted backend executor.
- Runtime or SEO writes bundled into this content-production scope.

## Separately Controlled Scope

Schema/source-policy changes, frozen-baseline replacement, batch expansion,
production infrastructure deploy, database migration, secrets/permissions,
irreversible deletion, and sitemap/`llms.txt`/Search Channel discoverability
need their own explicit scope. They are not inferred from a V2 package receipt
and are reported as scope or machine-gate blockers, not requests for an exact
approval phrase.
